Does deleting context pay?

b × L × r > S × (w - r)

Deleting b tokens from a cached prompt saves their cache read (r) on each of the L calls they would have stayed. It also forces the S tokens after them to be written to the cache again (w instead of r), once. The deletion pays only when the first side is larger.

Dollars are USD API list-price equivalent for one deletion: not live savings and not an invoice. Re-fetching deleted content later only makes a deletion harder to pay back; this page assumes none.

Calls to pay back when the tail is as large as the deletion (S = b) modeled, from list prices

With S = b the rule reduces to L > R. A small deletion early in a long prompt needs more calls; a large, late one needs fewer.
